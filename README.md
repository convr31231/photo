# ШАБЛОН — шаблон сайта фотостудии

Премиальный frontend-шаблон фотостудии на React + TypeScript + Vite.

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Контент

Все тексты, цены, залы, портфолио, услуги и изображения задаются в:

- `src/data/content.ts`
- `src/data/images.ts`

Замените URL фотографий и демо-данные на контент клиента — компоненты менять не нужно.

## Возможности

- Fullscreen hero с parallax / interactive reveal
- Preloader, кастомный курсор, magnetic-кнопки
- Залы, портфолио с lightbox, before/after
- Калькулятор съёмки и пошаговое бронирование
- Отзывы, FAQ, блог, контакты
- Адаптив, SEO, `prefers-reduced-motion`
